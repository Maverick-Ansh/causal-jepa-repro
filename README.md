# causal-jepa-repro

An annotated, from-scratch reproduction of **Causal-JEPA: Learning World Models
through Object-Level Latent Masking** ([arXiv:2602.11389](https://arxiv.org/abs/2602.11389),
Nam, Le Lidec, Maes, LeCun, Balestriero — ICML 2026).

Status: **work in progress** — see `REPORT.md` for results as they land.

Frontend: Google Colab (notebook UI). Backend: Kaggle 2x Tesla T4.
